# コード生成 {#codegen}

`@toride/codegen` は、Toride のポリシーファイルから TypeScript の型宣言を生成します。リソース名、ロール、権限、関係をコンパイル時に検証でき、入力ミスや不整合を実行前に検出できます。

## インストール {#installation}

::: code-group

```bash [pnpm]
pnpm add -D @toride/codegen
```

```bash [npm]
npm install -D @toride/codegen
```

```bash [yarn]
yarn add -D @toride/codegen
```

:::

::: tip ヒント
codegen は実行時ではなくビルド時に使うため、開発依存関係としてインストールしてください。
:::

## クイックスタート {#quick-start}

### 1. CLI の実行 {#_1-run-the-cli}

```bash
npx toride-codegen policy.yaml -o src/generated/policy-types.ts
```

ポリシーファイルを読み込み、生成した TypeScript 型を指定のパスに書き込みます。

### 2. 生成された型の使用 {#_2-use-the-generated-types}

生成ファイルには、ポリシーで定義されたすべてのリソース、ロール、権限、関係の型宣言が含まれます。

```typescript
// Auto-generated by @toride/codegen — do not edit

/** All action strings declared across all resources */
export type Actions = "read" | "update" | "delete" | "create_task";

/** All resource type names */
export type Resources = "Project" | "Task";

/** Per-resource role types */
export interface RoleMap {
  Project: "viewer" | "editor" | "admin";
  Task: "viewer" | "editor";
}

/** Per-resource permission types */
export interface PermissionMap {
  Project: "read" | "update" | "delete" | "create_task";
  Task: "read" | "update" | "delete";
}

/** Relation map — resource type -> relation name -> target resource type */
export interface RelationMap {
  Project: {
    org: "Organization";
  };
  Task: {
    project: "Project";
    assignee: "User";
  };
}

/** Per-type resolver map — TypeScript ensures all resource types have resolvers */
export type ResolverMap = {
  [R in Resources]?: (
    ref: { type: R; id: string; attributes?: Record<string, unknown> },
  ) => Promise<Record<string, unknown>>;
};
```

## CLI リファレンス {#cli-reference}

```
Usage: toride-codegen <policy-file> -o <output-file> [--watch]

Arguments:
  policy-file          Path to policy YAML or JSON file

Options:
  -o, --output <path>  Output file path (required)
  --watch              Re-generate on policy file change
  -h, --help           Show this help message
```

### 監視モード {#watch-mode}

`--watch` を指定すると、ポリシーファイルを変更するたびに型を再生成します。

```bash
npx toride-codegen policy.yaml -o src/generated/policy-types.ts --watch
```

開発中にポリシーを調整するときに便利です。

### JSON ポリシー {#json-policies}

CLI は JSON 形式のポリシーファイルにも対応しています。

```bash
npx toride-codegen policy.json -o src/generated/policy-types.ts
```

## プログラムからの利用 {#programmatic-api}

ジェネレーターはコードから呼び出すこともできます。

```typescript
import { generateTypes } from "@toride/codegen";
import { loadYaml } from "toride";
import { readFileSync, writeFileSync } from "node:fs";

const content = readFileSync("policy.yaml", "utf-8");
const policy = await loadYaml(content);
const types = generateTypes(policy);

writeFileSync("src/generated/policy-types.ts", types, "utf-8");
```

`generateTypes()` は解析済みの `Policy` オブジェクトを受け取り、TypeScript のソースコードを文字列として返します。

## 生成される型 {#generated-types-reference}

| 型 | 説明 |
|------|-------------|
| `Actions` | 全リソースの重複を除いた権限名のユニオン型 |
| `Resources` | 全リソース型名のユニオン型 |
| `RoleMap` | 各リソースをロールのユニオン型に対応付けるインターフェース |
| `PermissionMap` | 各リソースを権限のユニオン型に対応付けるインターフェース |
| `RelationMap` | 各リソースを、関係名と対象の型の対応を持つオブジェクトに対応付けるインターフェース |
| `ResolverMap` | リソース名をキーとする型付きリゾルバーマップ |

### 境界条件の扱い {#handling-edge-cases}

- **リソースがない場合**：`Actions` と `Resources` は `never` 型になります。
- **関係がない場合**：そのリソースの `RelationMap` は `Record<string, never>` になります。
- **安全でない識別子**：リソース名、ロール名、権限名、関係名を検証します。`[A-Za-z_][A-Za-z0-9_]*` に一致しないものがあると、コードインジェクションを防ぐためにエラーをスローします。

## ビルドへの組み込み {#adding-to-your-build}

`package.json` に `codegen` スクリプトを追加するのが一般的です。

```json
{
  "scripts": {
    "codegen": "toride-codegen policy.yaml -o src/generated/policy-types.ts",
    "codegen:watch": "toride-codegen policy.yaml -o src/generated/policy-types.ts --watch",
    "build": "pnpm codegen && tsc"
  }
}
```

ビルドごとに再生成する場合は、生成ファイルを `.gitignore` に追加できます。PR で差分を確認したい場合は、生成ファイルをコミットしても構いません。
